Privacy Policy for ToolPulse AutoPublisher

Last updated: September 9, 2026

1. Overview

ToolPulse AutoPublisher ("we", "our") is an automated video creation and distribution application designed to create and publish vertical video content across connected social media platforms.

2. Data We Collect

We do not collect personal data from visitors. Our application uses official OAuth API tokens to authenticate with TikTok, Meta (Facebook/Instagram), and YouTube for direct video posting purposes.

3. How We Use Data

OAuth tokens are securely stored in private repository environment variables and used strictly to execute scheduled video uploads to authorized channels.

4. Third-Party Services

Our app interacts with official APIs including TikTok Content Posting API, Meta Graph API, YouTube Data API v3, and Pexels API.

5. Contact Us

For inquiries regarding ToolPulse AutoPublisher, contact support via our GitHub repository.

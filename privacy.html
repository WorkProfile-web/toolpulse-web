Privacy Policy for ToolPulse AutoPublisher

Effective Date: September 9, 2026

ToolPulse AutoPublisher operates automated digital media distribution pipelines to create and post short-form vertical videos to connected social accounts.

1. Information Collection & Usage

ToolPulse AutoPublisher does not collect, store, sell, or share personal user data. Official API OAuth tokens are stored securely in private environment variables and used exclusively to execute authorized direct video uploads.

2. Platform APIs Used

Our application interacts directly with official APIs including TikTok Content Posting API, Meta Graph API (Facebook & Instagram), YouTube Data API v3, and Pexels API.

3. Data Retention & Revocation

No user profile data is retained on public servers. Users can revoke application access at any time through their respective TikTok or social platform account settings.
